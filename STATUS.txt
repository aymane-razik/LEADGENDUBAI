How To Start / Stop Manually
----------------------------
Start backend API: cd backend && npm run dev     (set PORT=5000 if a stale env var exists)
Start worker:     cd backend && npm run dev:worker
Start frontend:  cd frontend && npm run dev       (port 3000)
Stop all:         run stop-demo.bat  (or close the API, worker, and frontend windows)

Re-seed data:    cd backend && npm run seed:demo

Fix If Something Breaks
-----------------------
- "Node.js not found":  run-demo.bat now auto-detects C:\Program Files\nodejs
  and offers winget install. Node v24.19.0 is installed.
- Backend exits immediately: ensure MongoDB (27017) and Redis/Memurai (6379)
  services are Running:  powershell "Get-Service MongoDB,Memurai"
- PORT shows 0 in logs: a stale PORT env var is overriding .env -
  run with:  set PORT=5000 && npm run dev
- Frontend 500 on every page: PostCSS plugin missing -
  npm install -D @tailwindcss/postcss tailwindcss (already done)
